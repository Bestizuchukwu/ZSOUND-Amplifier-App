# ZSOUND Amplifier App

A premium amplifier control interface inspired by modern Apple-style glassmorphism and studio hardware dashboards.

## Features

- Touch-friendly UI built for MacBook, iPad, and Windows screens
- Dante connectivity status panel
- Studio-style output meters and signal monitoring
- Professional dark background with layered glow effects
- Responsive layout with soft, modern controls

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in the browser.

## Build

```bash
npm run build
```
